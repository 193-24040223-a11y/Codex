# 3D 야구 게임 기획안 (실제 야구 규칙 반영)

이 문서는 **실제 야구 규칙을 최대한 반영한 3D 야구 게임**의 최소 구현(MVP) 설계안입니다.

## 1) 게임 목표
- 9이닝 경기 운영
- 아웃 3개 시 공수 교대
- 실제 타격/주루/수비/심판 판정 흐름 구현
- 싱글 플레이(유저 vs AI) 우선

## 2) 핵심 실제 규칙

### 경기 진행
- 9이닝 기본, 동점 시 연장 이닝
- 초/말 공격 구분
- 각 이닝에서 아웃 3개 발생 시 공격 종료

### 스트라이크/볼/아웃
- 스트라이크 3개: 삼진 아웃
- 볼 4개: 볼넷, 타자 1루 진루
- 파울: 스트라이크 2개 전까지 스트라이크 증가
  - 단, 2스트라이크 이후 일반 파울은 스트라이크 추가 없음

### 타구 판정
- 페어/파울 판정 (1루/3루 라인 기준)
- 플라이 아웃
- 땅볼 아웃 (포스 아웃/태그 아웃)
- 홈런(페어 지역 담장 직통/넘김)

### 주루 규칙
- 포스 상황에서 강제 진루
- 태그업(뜬공 포구 후 진루)
- 도루 시도(성공/실패)
- 슬라이딩/태그 충돌 판정

### 득점
- 주자가 홈을 밟으면 1점
- 3아웃 이전 득점만 유효

## 3) 3D 게임플레이 루프
1. 투수: 구종/코스/구속 선택
2. 타자: 스윙 타이밍/배트 궤적 입력
3. 물리 계산: 공-배트 충돌, 스핀, 타구각 계산
4. 수비 AI: 낙하지점 예측, 송구, 베이스 커버
5. 심판 로직: 세이프/아웃/스트라이크/볼 판정
6. 주루 선택: 다음 베이스 진루/귀루

## 4) 시스템 아키텍처 (MVP)
- `GameState`: 이닝, 아웃카운트, 볼/스트라이크, 점수
- `RulesEngine`: 규칙 판정(타석 종료, 교대, 득점)
- `Physics`: 투구/타구/바운드/충돌 시뮬레이션
- `FieldingAI`: 수비수 위치선정, 포구/송구 의사결정
- `Umpire`: 타구/베이스 판정 결과 생성
- `UI/HUD`: 카운트, 이닝, 주자 현황, 점수판 표시

## 5) 데이터 모델 예시
```text
AtBatState {
  balls: 0..4
  strikes: 0..3
  outs: 0..3
  bases: [1B, 2B, 3B occupancy]
}

Runner {
  speed
  currentBase
  forceAdvance: bool
  canTagUp: bool
}

BattedBall {
  exitVelocity
  launchAngle
  sprayAngle
  spin
  isFair
}
```

## 6) 우선순위 로드맵
- P1: 타석/카운트/아웃/이닝 교대 규칙 완성
- P2: 기본 수비 AI + 포스/태그 아웃
- P3: 도루/태그업/희생플라이
- P4: 리플레이/통계/난이도 조정

## 7) 기술 스택 제안
- 엔진: Unity 또는 Unreal
- 물리: 엔진 기본 물리 + 커스텀 공기저항/스핀 모델
- 애니메이션: 모션 블렌딩(투구/타격/송구)
- AI: 상태머신 + 행동 트리

## 8) 테스트 체크리스트
- 삼진/볼넷/파울 카운트 규칙 검증
- 만루 상황 포스 아웃 로직
- 희생플라이 득점 인정 타이밍
- 9회말 끝내기 처리
- 동점 연장 이닝 점수 반영
